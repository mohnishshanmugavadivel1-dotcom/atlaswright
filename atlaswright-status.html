Prototype Systems

  • Procedural greybox terrain island (512m, 192-seg, seed 1337)
  • Bright biome gradient: sand / grass / forest / rock / snow
  • First-person movement: WASD + Shift run + Space jump
  • Mouse-gated movement (freezes when chart is open)
  • Water plane with alpha transparency
  • Warm atmospheric fog (density 0.003)
  • Sky: procedural gradient with horizon blending
  • Three cairn landmarks (A, B, C) with collision
  • Survey beacon placement (LMB, up to 24)
  • Aim alignment feedback (crosshair turns amber)
  • Bearing system with 4-deg sight-error threshold
  • Two-bearing resection (position fix math)
  • Closure error + mean sight error reporting
  • 2D chart: paper, grid, freehand ink strokes
  • World-aligned chart mapping (+/- 260m)
  • Fix stamping (cross markers on chart)
  • Undo stroke (Z key)
  • Publish button, read-only, PUBLISHED fade, close
  • HUD: instructions, compass heading, status line, crosshair
  • Terrain roughness 0.82 (specular depth cues)
  • Spawn inland with dry ring guarantee
  • Gentle 0.1m spawn (no jarring drop)

Deferred (GDD s10)

  • XP / currency / rewards
  • Progression / unlocks
  • Multiplayer / servers
  • Persistence / UGC sharing
  • Companies / certifications

Design Compliance

  • No XP / currency / rewards
  • No notifications
  • No social pressure
  • No dark patterns
  • No FOMO / battle pass
  • Natural stopping point (Publish)
  • Intrinsic motivation loop
  • Survey / Draw closure
